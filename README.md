# Portafolio Dinámico

Portafolio full-stack con panel de administración privado para gestionar mis proyectos. En construcción — se actualiza a medida que avanzo el curso.

## 🚧 Estado actual
Unidad 1 (Intro a CSS y HTML) completa: estructura base en HTML y estilos en CSS (selectores, box model, padding, border-radius). Todavía sin interactividad ni backend — eso llega en las próximas unidades. 

## 🛠️ Stack (por ahora)
- HTML5
- CSS3

*(Se va a sumar JavaScript, React, Node/Express y SQL a medida que avance el curso.)*

## ✅ Funcionalidades actuales
- Sección de presentación (nombre).
- Foto de perfil.
- Sección "Sobre mí".
- Enlaces de navegación.

## 💻 Cómo verlo localmente
```
git clone https://github.com/tu-usuario/portafolio-dinamico.git
cd portafolio-dinamico
```
Abrí `index.html` en el navegador. No requiere instalación por ahora (sin dependencias todavía).

## 📚 Qué estoy aprendiendo con este proyecto
Estoy retomando el recorrido Full-Stack de Mimo después de una pausa, y decidí no rehacer los ejercicios sueltos sino construir un proyecto real que crezca unidad por unidad. Esta primera etapa consolidó:
- Estructura semántica básica de HTML.
- El modelo de caja (box model) en CSS: content, padding, border, margin.
- Flujo de trabajo con Git: una rama y un Pull Request por unidad, con commits incrementales dentro de cada una.

## 🗺️ Próximos pasos (19 unidades restantes)
- Flexbox y Grid para el layout general.
- JavaScript para interactividad (formulario de contacto, filtros).
- Migración a React.
- Backend con Express + base de datos SQL.
- Panel de administración con login.
